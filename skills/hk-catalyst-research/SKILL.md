# HK Catalyst Research

For each unusual mover (or sector cluster), find the real catalyst and write actionable framing. **Success = narrative that can change position weight** (sector linkage / policy second-order / A–H / retail crowding vs tape) — not longer markdown or more websites scanned every day.

## Baseline sources (every run)

1. **HKEX announcements** and company filings first
2. Then news: Bloomberg, Reuters, SCMP, Caixin, ETNet, Ming Pao / HKEJ, company PRs
3. Cross-check with ≥2 sources. Cite inline `[來源，日期]`. Never invent quotes or numbers.

Keep daily tape/Monitor/TV AV pipelines unchanged; this skill only deepens **catalyst stories**.

## Trigger triad (per seed / cluster) — ask before writing depth

After the baseline pass, for each AV seed or active sector cluster ask:

1. **Policy gate?** Material mainland or HK policy/regulatory move (same day **or T−1** primary text) that maps to today’s movers?
2. **Gelonghui theme?** Credible institutional / thematic narrative on a catalyst day?
3. **Futu crowding?** HK retail positioning / sentiment that diverges from or confirms Market Monitor / **北水（northbound／Stock Connect 北向）**?

Only pull the matching Focus source when the answer is plausibly yes. **Do not** daily-sweep Xueqiu, Gelonghui, Webull, Futu, and policy sites.

### Focus A — China / HK policy (primary text, trigger-only)

**Watch ladder (primary):** State Council / gov.cn → NDRC → MIIT / MOFCOM → PBOC → CSRC / exchanges → Xinhua / People’s Daily / CCTV (official calibration only). **HK:** HKMA / SFC / HKEX.

**Write-in gate (all required):**
- Primary text is openable (URL or filing id) — **same-day or T−1** primary is OK
- Aligns to **same-day** AV / sector **or** **北水（northbound）** / A–H / heavyweight sector linkage
- Write only **one sentence of primary + second-order implication** for the tape

Else: omit, or note a one-line 資料缺口 — do not paraphrase rumor as policy.

### Focus B — Gelonghui (catalyst days)

Use for **institutional / thematic narrative** around the day’s clusters. Label as secondary narrative with `[格隆匯，日期]`. Contrast to tape; never treat as price/volume authority. Skip if you would be forcing a theme.

### Focus C — Futu (catalyst days)

Use for **HK retail crowding** contrast vs Market Monitor pulse and **北水（northbound）**. One sentiment sentence + contrast when crowding is clear; otherwise omit. Label as sentiment, not fact.

**Xueqiu:** optional A-share retail substitute only when Futu is missing **and** the theme is A-share-heavy — **do not run both** the same day. **Webull:** do not add (low ROI).

## Classify & story type

1. Classify catalyst: earnings, policy, M&A, analyst note, product, rumor (label rumor clearly), or unexplained
2. Story type:
   - **Sector-driven headline** if ≥3 same-sector names move together
   - **Single-stock headline** if one name has material market news
3. Verify tickers as `XXXX.HK 中文名稱` against HKEX records

## Primary vs secondary in the write-up

- **Primary** (HKEX / filings / policy original) = main clause of **發生什麼事**
- **Secondary** (Gelonghui / Futu / Xueqiu) = labeled narrative or sentiment — never as confirmed fact
- ≥2 sources; rumors must be labeled

## Story bullets (every headline)

- **發生什麼事** — specific catalyst + data (primary first)
- **哪些股票異動** — tickers, % change, volume multiple (HKEX-primary for tape; AV seeds as handed)
- **可行動洞察** — sustainable? impact tomorrow / next week? Include second-order only when a Focus trigger fired

## Depth appendix (optional section)

Add a short **深度附錄** only when **any** of:
- ≥2 seeds share one theme
- Policy write-in gate passed
- Earnings + rating double-hit needs sector / A–H linkage

Appendix = primary link(s) + second-order only. Otherwise keep the three main headlines lean; no appendix filler; do not inflate the main skeleton on no-trigger days.

## Outside judge

Primary filings/policy URLs must be checkable. Work Verifier validates facts/citations — **not** social sentiment. Do not ask WV to bless Xueqiu/Futu tone. No source → 「未見明確催化劑」 or 資料缺口.

## Anti-jobs

- No unsourced catalysts; no wrong tickers
- No daily full sweep of Xueqiu / Gelonghui / Webull / Futu / policy portals
- No treating social or broker-app sentiment /自媒體 as tape or policy fact
- No Webull as a standing source
- No Xueqiu + Futu double-read the same session
- No “據傳政策” without openable primary text
- No padding length on no-trigger days
- Skip names with no verifiable driver unless flagged as 「未見明確催化劑」
