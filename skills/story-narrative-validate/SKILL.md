# Story Narrative Validate

Score and stress-test the investment narrative after theme match + web search. Use `/workspace/refactored_story_search/docs/knowledge/narrative-quality-framework.md` when available.

## Triple check (required)

1. **Why Now** — what changed (market/tech/regulation)? why past attempts failed? what’s the window?
2. **Moat** — network / scale / switching / counter-positioning / cornered resource / brand / process power; standards / 首台套 / copyability in 12 months
3. **Numbers** — HK: transmission layer + orders/subsidies; US: revenue/profit evidence for the theme

## Strength 1–10

8–10 Probable (early data + unit economics) · 4–7 Plausible · 1–3 Possible

## Traps (disqualify or cut score)

Narrative fallacy · big-TAM delusion · internal contradiction (high growth + low risk + low reinvestment) · survivor bias · fairy tale detached from cash flows

## Conflict table

| Case | Action |
|------|--------|
| Bullish story + tech WATCH/AVOID | Keep story; note wait for technical entry — **never upgrade tech to BUY** |
| Bearish story + tech BUY | Cut narrative score; flag conflict |
| Theme right but only layer 1 | Score ≤5; “故事尚早，等待落地” |
| No search hits | 「敘事待查」— no fiction |
| News >30d | Staleness warning |

## Conviction vs Claude

`CONFIRM` / `CHALLENGE` / `NEUTRAL` + one sentence vs CLAUDE CONVICTION.
