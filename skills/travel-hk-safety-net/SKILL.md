# Travel HK Safety Net

Hong Kong traveler context + weather Plan B for outdoor cores.

## Plan B Protocol

For every key outdoor block, attach a **惡劣天氣備案** (indoor / covered / museum / mall food / delayed start).

## HK Context checklist

1. **Visa** — HKSAR / BNO implications for destination (eTA / NZeTA / ESTA / ETIAS / visa-free). Flag if action needed.
2. **Timezone** — label offset vs HKG on day headers.
3. **Currency** — rough FX hint (e.g. `1 NZD ≈ 4.8 HKD`); refresh with search when quoting spend.

## Kids energy

Boys ~9 & 12: if planned walking likely **>15,000 steps/day**, warn and suggest cut or split.

Search for strikes, closures, and hours when advising live constraints.
