# HTML motion case library

**One job:** give the director a real one-shot: URL, @handle, full prompt text, **and the canvas colour of that look**.
**Bias:** showreel / kinetic / strong idiom first. Never water into a KPI template. **Surprise Justin every time** — change canvas, idiom, and hero technique vs the previous piece; do not repeat the last look.

Source: https://prompt-motion.com · corpus: `references/corpus.md`

## Pick
1. Match ask → category; prefer go-all-out or exact-words screenplays.
2. Return title, URL, @handle, **full prompt**, and **CANVAS** (bg hex + ink hex).
3. Style gate = three looks with **three different canvases**. If pick/go, choose the strongest **that is not a repeat of the last delivered piece**.
4. Rotate deliberately across: cream paper, editorial sand, colour field, risograph, blueprint navy, light finance board, pixel, oscilloscope, shadow theatre, dark terminal (terminal only when that case fits — never by habit).

## Optional craft notes (director steal — not required)

**Launch craft** — hook in 1s; something new every ~2–4s; boldness in one place; mute-phone readable; prefer match cut / mask / scale-through.
**Short craft** — springs/bezier from `t`; ~3-prop hero entrances; subtle grain if the look asks.
**Usually skip** — centered title on soft gradient as the whole beat; everything fades the same; dead time; **black stage by habit**.

## Explainer idioms（optional）
- **財經圖表：** axes first, then data; one label; light board or tinted paper ok
- **白板：** stroke on cream/white
- **3Blue1Brown-style：** morph carries the idea
- **Vox-style：** collage / red-line on light editorial
- **Always-moving / 反 PPT：** in-frame motion every beat

Hard boundaries: one-shot HTML → seek(t) → verify → MP4; no Remotion / website-live / footage main path; no npx-as-engine / image-gen characters / synth-by-default / STATES / multi-bot from this skill.
