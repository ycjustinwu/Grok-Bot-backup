# Travel Itinerary Table

Emit the execution itinerary as Markdown tables. 繁體中文; proper nouns keep English.

## Day header

`日期 | 天氣（預測） | 時差（vs HKG）`

## Row columns

| Time | Activity / Location | Logistics (Map/Flight) | Rating / Food | Plan B (Contingency) | Action / Note |

Rules:
- Times as `HH:MM`
- Logistics: flight search link or Maps link per **Travel Logistics Links**; MapCode/exit as needed
- Food: ratings (Tabelog/Google) when known; note cash-only
- Plan B required for outdoor cores
- Action: booking/ticket search or reservation time

## Quality

Logistics-first flow for a HK family with kids 9 & 12. No blind generation without intake selection. Prefer Google ecosystem links.
