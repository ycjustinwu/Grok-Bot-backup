# YouTube Analyzer（Deep）

寫給繁體中文科技／投資讀者。摘要是唯一文本，讀者不會重看影片。深度來自因果與場景，不來自修辭或加長。風格對標 Kelileo CUP（Cupsir）市場資訊筆記 PDF 金標（2026-11-09 Stan Weinstein／TraderLion 樣本鎖定）。

## 模式選擇（先選再寫）

| 條件 | 模式 |
|---|---|
| 市場／財經 podcast、週報、債股事件、IPO／估值辯論、宏觀週刊 | **市場資訊筆記**（預設） |
| Justin 明確說「市場資訊筆記」 | **市場資訊筆記** |
| 教學方法片、交易系統拆解、非行情訪談、工程／產品深談 | **影片詳細摘要** |
| 拿不准 | 偏市場／數字多 → 市場資訊筆記；偏方法／清單 → 影片詳細摘要 |

兩種模式共用：深度門檻、全名紀律、數字紀律、不腦補字幕、不構成投資建議、永不 WATCH→BUY。

## 深度門檻

不合格：`小團隊隔離一個月做出原型。`

合格：寫出如何隔離、為何隔離、一個場景。反事實、玩笑、第二個例子另開一則，不塞進同一則。

寫完仍須有：場景、因果、張力、原話或近原話、片中後段。缺一就補。字幕截斷處寫「逐字稿此處中斷」，禁止腦補。

篇幅：約 70–90 分鐘市場訪談 **按機制收成 8–10 節**；約 40 分鐘教學片 8–12 節。短片按比例縮。不要為對齊時間軸製造空節，也不要為好讀刪掉殺手級例子。開場寒暄／登頂玩笑／廣告 **不得獨立成節**，併入第一個機制節或標為已刪贊助。

## Cupsir PDF 金標對齊（2026-11-09 鎖定；取代舊「港式口語優先」）

1. **開篇論文**：標題後先寫一段總論（3–8 句），可織入已核外部關鍵數字；再「項目｜內容」資訊表；再免責＋贊助刪除聲明；再目錄。
2. **講者全名＋職銜**：來自片中或已核材料；搜不到標明，禁止猜姓。
3. **機制切段＋小數編號**：大節用「一、二、…」；節內用 `1.1 / 1.2` 小節，不照搬官方章節標題；相鄰同框架合併。
4. **表只在有內容時出現**：事件收市表、關鍵位表、階段對照、長短倉案例、觀察名單、指標追蹤表；禁止空表。
4a. **Notion／Markdown 可讀性（2026-11-09）**：所有表必須用 **GitHub-flavored Markdown pipe tables**（`| col |` + `|---|`）。禁止用空格對齊的純文字表；禁止把表拆成硬換行段落。資訊欄、收市對照、案例、觀察名單、「要留意的地方」一律 pipe table。交付 Notion 前自檢：頁面內每個表在 fetch 後仍顯示為 table block，而非一長串 `<br />`。
5. **「所以怎樣：」收束**（市場筆記預設）：每重大節末用引用框寫一句機制命題＋短推論；可另加 2–4 條判斷條件。舊「本節重點」口令式清單降為可選補強，不得取代「所以怎樣」。
6. **來源與書目分離**：節內可標字幕時間戳或「講者口述」；**外核數字必須標日期＋來源**；文末獨立「資料來源」書目（URL＋檢索日），影片逐字稿不混入書目。
7. **數字與信心紀律**：講者數字照錄並標「講者自述，未經核實」若屬戰績／持倉；外核永不寫進講者口中；逐字稿歧義用「校正說明」＋信心（高／中／低）。
8. **收束**：最後機制節固定為「要留意的地方」（欄：指標｜現況（含日期）｜要問的問題）；其後「資料來源」。可選「全篇重點」「片中沒給的財務數字清單」「核對備註」。不把 WATCH 升成 BUY。
9. **語體**：全文繁體。**市場筆記偏書面繁中**（對齊 Cupsir PDF）；方法片維持書面繁中。港式口語（嘅／咗／唔）僅在 Justin 明確要求或方法片對話節奏需要時少量使用，不得作為市場筆記預設。術語第一次白話解釋；中英之間一格空格。
10. **贊助／廣告**：Deepvue、課程、刊物試用等與市場機制無關片段全數刪除，並在開篇用「贊助內容：…已全數刪除」聲明。

## 外核規則（市場筆記）

為對齊 Cupsir 資訊密度，市場筆記 **必須** 嘗試查片外公開數字（尤其當日／當週指數與 ETF 收市），但只能放在：

- 節首事件小節的 **表**（收市、跌幅、關鍵位）
- 「校正說明」／信心註
- 「要留意的地方」的「現況（含日期）」欄
- 文末「資料來源」書目

禁止：把外核股價／報章數字寫成講者說過的話；禁止搬入二創筆記的終值公式或未標來源價表。

查不到就留空或寫「片中未給／未核到」，不准估。

## 文筆規則（12）

1. 離開影片仍須看懂。術語當主語、主語寫「他」、一則轉場三次，都算不合格。
2. 主持與嘉賓用搜到的全名和職銜。字幕只有名就搜。搜不到寫「片中僅稱名，未核到姓」，禁止猜。
3. 官方章節是覆蓋清單，不是標題。市場／長訪談目標 **8–10** 機制節；方法片可至 12。資訊表後先寫論文；生平壓成一張表或併入框架節；片尾不得變薄。
4. 清單課預設一變數一節。該變數不足兩則、又沒有獨立例子，才可與相鄰變數合併，標題列出編號。
5. 主持只接話就併進敘事。有獨立主張才另開觀點。
6. 三種以上命名類型用表。交易／市場片有講到或外核到才做表：時間線、關鍵位、階段對照、長短倉案例、觀察名單、有用與無用指標。禁止空表。
7. 數字、引語、職銜、日期：講者材料照錄；外核僅按「外核規則」。矛盾並列。示範算術標「示範」。
8. 保留收束與可選「片中沒給的財務數字清單」。不把 WATCH 升成 BUY。不給投資建議。
9. 殺手級例子跟它所證明的規則走。缺了補回原節，不另開補丁節。
10. 缺稿就標缺。官方章節有到哪裡，摘要就跟到哪裡。
11. 「所以怎樣」是機制命題；若另寫判斷條件，每條必須可執行／可觀測，不准複述正文，不准寫流程元指令。
12. 方法片用診斷次序收束。只寫講者支持的檢查項。書單與生活保留，不得擠掉診斷。

## 行文規則

- 粗體只寫讀者一看就懂、能帶走的規則。不寫修辭比喻，不寫「規則：」當每則前綴。
- 一則最多 3 句：主張、原因、一個例子。反事實、玩笑、第二個例子拆成下一則。
- 主語用全名（如 Stan Weinstein、Richard Moglen）。不用「他」。
- 術語第一次出現用一句白話解釋，再用中文名。代碼第一次要加公司身份。
- 全文繁體。中文與英文之間留一格空格。不夾簡體字。
- 括號不超過每則一處。字幕校正集中「校正說明」或「核對備註」。
- 價位寫成路徑，用來證明規則，不散落展覽。
- 每節不假設讀者讀過上一節。禁止「如上」「前述那張圖」。

## Workflow

1. 抽出 URL（youtube.com / youtu.be / Shorts）與可選主題焦點；選定模式（市場資訊筆記／影片詳細摘要）。
2. 先蒐集再寫：標題、頻道、上傳日、長度、全名與職銜、官方章節、逐字稿。**字幕優先自取**（yt-dlp／innertube timedtext／page extract／WebFetch）；**僅在自取失敗或不足時**才問 Video Transcriber。一直抓到片尾。某段只有標題沒有正文，標明缺口。
3. 市場筆記：另蒐最少必要外核（當日／當週指數與 ETF 收市、關鍵報章跌幅歸因、講者書目／職銜核對）；查不到就跳過該格並在書目標「未核到」。
4. 數字、引語、職銜、日期只按模式規則寫入；贊助片段刪除並聲明。
5. 用下方對應 Output Format 寫。指定主題仍須 Deep。
6. 回覆用 GitHub-flavored Markdown；另存 `/workspace/youtube-analyzer-deep/<date-or-slug>.md`；聊天附上該檔。Notion 同步時 **全文 inline** 為 page body（`$file:`），勿只 stub＋附件。除非 Justin 明確要求，不上傳 Drive。

## Output Format A — 市場資訊筆記（Cupsir PDF 金標）

標題行：

`【市場資訊筆記】[講者或頻道]｜[中文機制主題]｜[YYYY 年 M 月 D 日]`（錄影日不明可寫「推斷」並在資訊表說明）

開篇順序（固定）：

1. **總論**（3–8 句）：事件＋講者定位＋核心判斷，可織入已核外部數字。
2. **資訊表**（項目｜內容）：來源（節目／主持／原題）、講者（書名／職銜）、錄影／上載日期、長度、數字說明。
3. **免責聲明**（固定短段：觀點屬講者；不構成投資建議）。
4. **贊助內容聲明**（若片中有廣告／平台推廣：註明已刪除；無則省略此段）。
5. **目錄**（一～N；最後一節標題用「要留意的地方」；「資料來源」列在目錄末或不進目錄但文末必有）。

每節：

### 一、[中文機制標題]

### 1.1 [小節]

正文（書面繁中；全名；一則最多 3 句）。有內容才出表。

校正說明：（逐字稿歧義時；含信心）

> **所以怎樣：** [一句機制命題＋短推論]

（可選）判斷條件 2–4 條。

來源：影片字幕（mm:ss 至 mm:ss）或講者口述；外核見文末書目。

最後兩塊（固定）：

### N、要留意的地方

表欄：**指標｜現況（含日期）｜要問的問題**

### 資料來源

條列外核：媒體／書目／播客列表；各附 URL＋報道或檢索日期。註明「影片內容（逐字稿）為講者口述，未列於此」。

（可選）全篇重點、片中沒給的財務數字清單、核對備註。

## Output Format B — 影片詳細摘要（方法／非行情訪談）

### 影片詳細摘要

**標題：** [原題]  
**頻道：** [頻道]  
**連結：** [用戶給的 URL]  
**上傳日期：** [年月日]  
**長度：** [時長]  
**主持人／講者：** [全名（頭銜，用材料裡出現過的）]

> 以下為影片內容的極詳細摘要，包含[本集實際主題 4–8 個，用頓號列出]。內容屬訪談／公開分享整理，不構成投資建議。以下針對[TOPICS]做 summary。

無指定主題時，[TOPICS] 改為「全片內容」。資訊表後先寫一句論文。方法片按機制切。官方章節只當覆蓋清單。書面繁中為主。

每節：

### [中文標題]

**[講者全名] 的觀點**

用 `-` 子彈。一則最多 3 句。

**本節要點**

兩至四條編號。每條是一個動作或一個判斷條件（禁止流程元指令）。

**總結：** 一句話，含一個具體事實。

來源：影片字幕（mm:ss 至 mm:ss）。

片尾閃電回合、書單、使用建議照樣成節。最後加「全片收束」與「片中沒給的財務數字清單」。文末「核對備註」。

## Missing-input

- 沒 URL：要連結。
- 片失效：報告後停止。
- 指定主題片中沒有：明說沒有。
- 字幕只到半場：寫到已有材料為止，並列出未覆蓋的官方章節名稱。
- 外核失敗：表格該格留空或註「未核到」，不阻正文交付。
