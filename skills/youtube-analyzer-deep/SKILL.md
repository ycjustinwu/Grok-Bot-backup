# YouTube Analyzer（Deep）

寫給繁體中文科技／投資讀者。摘要是唯一文本，讀者不會重看影片。深度來自因果與場景，不來自修辭或加長。風格對標 Kelileo CUP（Cupsir）市場資訊筆記：有場景、因果、張力、原話或近原話、片中後段、時間戳來源；禁止腦補字幕缺口。

## 模式選擇（先選再寫）

| 條件 | 模式 |
|---|---|
| 市場／財經 podcast、週報、債股事件、IPO／估值辯論、宏觀週刊 | **市場資訊筆記**（預設） |
| Justin 明確說「市場資訊筆記」 | **市場資訊筆記** |
| 教學方法片、交易系統拆解、非行情訪談、工程／產品深談 | **影片詳細摘要** |
| 拿不准 | 偏市場／數字多 → 市場資訊筆記；偏方法／清單 → 影片詳細摘要 |

兩種模式共用：深度門檻、全名紀律、數字紀律、不腦補字幕、不構成投資建議、永不 WATCH→BUY。

## 深度門檻

不合格：`小團隊隔離一個月做出原型。`

合格：寫出如何隔離、為何隔離、一個場景。反事實、玩笑、第二個例子另開一則，不塞進同一則。

寫完仍須有：場景、因果、張力、原話或近原話、片中後段。缺一就補。字幕截斷處寫「逐字稿此處中斷」，禁止腦補。

篇幅：約 80–94 分鐘 **按機制收成 8–10 節**（市場筆記尤甚）；約 40 分鐘教學片 8–12 節。短片按比例縮。不要為對齊時間軸製造空節，也不要為好讀刪掉殺手級例子。開場寒暄／登頂玩笑／廣告 **不得獨立成節**，併入第一個機制節。

## Cupsir 樣本對齊（反推；2026-10-18 All-In 對照後更新）

1. **開篇論文**：資訊表後先寫一段總論（光譜／主線／為何要讀）；市場筆記再加目錄。
2. **講者全名＋職銜**：來自片中或已核材料；搜不到標明，禁止猜姓。
3. **機制切段**：按因果機制／劇本／方法切，不照搬官方章節標題；相鄰同框架合併。
4. **表只在有內容時出現**：股價／CDS／Polymarket／時間線／條件對照／指標表；禁止空表。
5. **本節重點（市場）／本節要點（方法）**：每條是機制判斷條件或可執行檢查（2–4 條），不複述正文，不准寫流程元指令（禁止「先分清角色」「先讀 CDS」這類口令當要點）。合格例：`CoreWeave 嘅問題唔係無生意，而係融資：…`
6. **來源行**：每節末標字幕時間戳；**允許同節附加外核來源**（見「外核規則」）。字幕校正仍集中「核對備註」。
7. **數字紀律**：講者數字照錄並標出處；示範算術標「示範」；矛盾並列不刪句求順。外核數字永不寫進講者口中。
8. **收束**：全片／全篇重點＋片中沒給的財務數字清單；市場筆記另加「之後可以留意嘅指標」表。不把 WATCH 升成 BUY；不給投資建議。
9. **語體**：全文繁體。市場筆記模式可用港式口語節奏（嘅／咗／唔／係）；方法片維持書面繁中。術語第一次白話解釋；中英之間一格空格。

## 外核規則（市場筆記）

為對齊 Cupsir 資訊密度，市場筆記 **可** 查片外公開數字，但只能放在：

- 節首「發生咩事」後的 **表／圖示意說明**（股價週表、CDS／債價、Polymarket 讀數、現金流次序示意）
- 該節 **來源行**（例：`來源：影片字幕（2:18 至 13:31）；股價：Massive；CDS：Reuters／roic.ai`）
- 文末「核對備註」與「之後可以留意嘅指標」的「而家讀數」欄

禁止：把外核股價／CDS／報章數字寫成講者說過的話；禁止搬入二創筆記的終值公式或未標來源價表。

查不到就留空或寫「片中未給／未核到」，不准估。

## 文筆規則（12）

1. 離開影片仍須看懂。術語當主語、主語寫「他」、一則轉場三次，都算不合格。
2. 主持與嘉賓用搜到的全名和職銜。字幕只有名就搜。搜不到寫「片中僅稱名，未核到姓」，禁止猜。
3. 官方章節是覆蓋清單，不是標題。市場／長訪談目標 **8–10** 機制節；方法片可至 12。資訊表後先寫論文；生平壓成一張表或最後一節；片尾不得變薄。
4. 清單課預設一變數一節。該變數不足兩則、又沒有獨立例子，才可與相鄰變數合併，標題列出編號。
5. 主持只接話就併進敘事。有獨立主張才另開觀點。
6. 三種以上命名類型用表。交易／市場片有講到或外核到才做表：時間線、風險與連虧、接受與拒絕條件、一週股價、CDS／債價、Polymarket、錯法對照、有用與無用指標。禁止空表。
7. 數字、引語、職銜、日期：講者材料照錄；外核僅按「外核規則」。矛盾並列。示範算術標「示範」。
8. 保留全片／全篇收束與「片中沒給的財務數字清單」。不把 WATCH 升成 BUY。不給投資建議。
9. 殺手級例子跟它所證明的規則走。缺了補回原節，不另開補丁節。
10. 缺稿就標缺。官方章節有到哪裡，摘要就跟到哪裡。
11. 「本節重點／要點」每條是一個機制判斷條件或可執行檢查，兩至四條。不准複述正文，不准寫情緒評論，不准寫「本節篩選的是」，不准寫流程元指令。
12. 方法片用診斷次序收束。只寫講者支持的檢查項。書單與生活保留，不得擠掉診斷。

## 行文規則

- 粗體只寫讀者一看就懂、能帶走的規則。不寫修辭比喻，不寫「規則：」當每則前綴。
- 一則最多 3 句：主張、原因、一個例子。反事實、玩笑、第二個例子拆成下一則。
- 主語用全名（如 Matt Caruso、Jason Shapiro、Ed Yardeni）。不用「他」。
- 術語第一次出現用一句白話解釋，再用中文名。代碼第一次要加公司身份。
- 全文繁體。中文與英文之間留一格空格。不夾簡體字。
- 括號不超過每則一處。字幕校正集中「核對備註」。
- 價位寫成路徑，用來證明規則，不散落展覽。
- 每節不假設讀者讀過上一節。禁止「如上」「前述那張圖」。

## Workflow

1. 抽出 URL（youtube.com / youtu.be / Shorts）與可選主題焦點；選定模式（市場資訊筆記／影片詳細摘要）。
2. 先蒐集再寫：標題、頻道、上傳日、長度、全名與職銜、官方章節、逐字稿（優先平台字幕／Video Transcriber／Tavily extract；一直抓到片尾）。某段只有標題沒有正文，標明缺口。
3. 市場筆記：另蒐最少必要外核（當日／當週股價、CDS／債價報道、Polymarket 頁面讀數、關鍵報章數字）；查不到就跳過該格。
4. 數字、引語、職銜、日期只按模式規則寫入。
5. 用下方對應 Output Format 寫。指定主題仍須 Deep。
6. 回覆用 GitHub-flavored Markdown；另存 `/workspace/youtube-analyzer-deep/<date-or-slug>.md`；聊天附上該檔。Notion 同步時 **全文 inline** 為 page body（`$file:`），勿只 stub＋附件。除非 Justin 明確要求，不上傳 Drive。

## Output Format A — 市場資訊筆記（預設於市場／財經集）

標題行：

`【市場資訊筆記】[頻道或講者]｜[中文機制主題]｜[YYYY年 M月 D日]`

開篇：3–6 句總論（今集拆成幾條主線）→ 資訊欄（撰寫日期、來源影片、主持、嘉賓、涵蓋主題、資料來源、數字說明、筆記作者可用 YouTube Analyzer Deep）→ **目錄**（一、二、…）→ 短免責（不構成投資建議）。

每節：

### 一、[中文機制標題]

**發生咩事**（可選但市場事件集強烈建議）：用 2–4 句交代觸發事件與時間線。

有內容才出表／示意（股價週表、盒子現金流次序、Polymarket 讀數等）。

其後按講者／機制寫正文（可用小標 `Chamath：…`）；港式口語節奏可；全名；一則最多 3 句。

**本節重點：** 先一句機制命題，再 2–4 條編號判斷條件。

來源：影片字幕（mm:ss 至 mm:ss）；[外核標籤：出處]。

最後：

### 八、之後可以留意嘅指標

表欄：指標｜要問嘅問題｜而家讀數（片中有／外核核到才填）。

**全篇重點：** 2–4 條（機制級，不是流程口令）。

**片中沒給的財務數字清單**＋**核對備註**。

## Output Format B — 影片詳細摘要（方法／非行情訪談）

### 影片詳細摘要

**標題：** [原題]  
**頻道：** [頻道]  
**連結：** [用戶給的 URL]  
**上傳日期：** [年月日]  
**長度：** [時長]  
**主持人／講者：** [全名（頭銜，用材料裡出現過的）]

> 以下為影片內容的極詳細摘要，包含[本集實際主題 4–8 個，用頓號列出]。內容屬訪談／公開分享整理，不構成投資建議。以下針對[TOPICS]做 summary。

無指定主題時，[TOPICS] 改為「全片內容」。資訊表後先寫一句論文。方法片按機制切。官方章節只當覆蓋清單。書面繁中為主。

每節：

### [中文標題]

**[講者全名] 的觀點**

用 `-` 子彈。一則最多 3 句。

**本節要點**

兩至四條編號。每條是一個動作或一個判斷條件（禁止流程元指令）。

**總結：** 一句話，含一個具體事實。

來源：影片字幕（mm:ss 至 mm:ss）。

片尾閃電回合、書單、使用建議照樣成節。最後加「全片收束」與「片中沒給的財務數字清單」。文末「核對備註」。

## Missing-input

- 沒 URL：要連結。
- 片失效：報告後停止。
- 指定主題片中沒有：明說沒有。
- 字幕只到半場：寫到已有材料為止，並列出未覆蓋的官方章節名稱。
- 外核失敗：表格該格留空或註「未核到」，不阻正文交付。
