# Story Web Search

Run **exactly three** focused web searches for company-specific facts. Do not re-search the built-in macro framework. Prefer connector/web search tools; cite title + URL. Never invent results.

## HK queries

1. `[公司名稱] [主線關鍵詞] 訂單 補貼 2026`
2. `[公司名稱] 北水 港股通 機構買入 最新`
3. If VERDICT BUY/STALK/WATCH: `[公司名稱] 業績 催化劑 分析師目標價`  
   If AVOID/PASS: `[公司名稱] 監管風險 政策變化`

## US queries

1. `[TICKER] [Trend keyword] 2026`
2. `[TICKER] earnings catalyst analyst upgrade 2026`
3. If BUY/STALK/WATCH: `[TICKER] institutional flow ETF inflow`  
   If AVOID/PASS: `[TICKER] risk downgrade bearish`

## Earnings overlay

If EARNINGS ≤14 days, bias queries to **pre-earnings** catalysts only. If PASS ≤7 days, same-week only.

## After search

- News older than 30 days → tag `⚠️ 資訊可能過時，建議人工核實`
- No hits → leave narrative as 「敘事待查，主要基於技術面」— do not fabricate
