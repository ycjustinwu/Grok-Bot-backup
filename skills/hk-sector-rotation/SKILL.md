# HK Sector Rotation

Analyze Hang Seng industry / sector performance for the after-close brief. Only report sectors with material moves or headline news.

## Discovery sources (check first)

1. **HKEJ Stock360 Industry（行業熱圖）** — https://stock360.hkej.com/marketWatch/Industry — primary visual for which industries lit up today
2. Hang Seng industry / composite industry index prints (official when available)
3. Cross-check leaders/laggards via Spot — https://stock360.hkej.com/marketWatch/Spot

Industry heatmap is for **discovery and clustering**; prefer official index / HKEX-linked figures for % when citing.

## Steps

1. Open HKEJ Industry heatmap; note hot/cold industries. Also pull Hang Seng industry indices (all 11) % change for the session when available.
2. **Keep only** sectors that matter today:
   - Index move >2% up or down
   - Clear volume / flow anomaly
   - Or a headline story tied to that sector
3. Priority watch list when active: tech (AI, internet), healthcare/pharma, auto/EV, consumer, property, banks, insurance, industrials
4. For each active sector write:
   - Sector name + index % (or heatmap-relative move if official index missing — label the source)
   - Main driver (policy, earnings, rotation signal)
   - **Leaders vs laggards** inside the sector when useful
   - Note A-share vs H-share divergence when obvious
5. Cite sources `[來源，日期]`. Prefer official index / HKEX-linked figures.

## Anti-jobs

- Do not dump all 11 sectors if most are quiet.
- Do not invent index levels.
