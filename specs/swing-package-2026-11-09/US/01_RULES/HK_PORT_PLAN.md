| 缺 | 影響 |

| **三個閘門** | 直接輸出 `Action_Refined`（= 給了 verdict），v5 已禁止 |

### 一個有價值的線索：港股版的底部門檻可能要比美國寬

舊提示詞 v4.7.1 明寫 Tight Zone v2.1 是「**放寬版（HK 2026-09）**」：
量門檻 0.70 → **0.85**、波幅 1.0 → **1.2×ADR**、天數 3–7 → **2–10 日**、豁免 1 → **2 日**。

我們 v5 的 base 用 `range ≤ 1.0×ADR`、`vol < 0.85×Vol20`。
→ **量門檻已經對上（0.85），但波幅門檻仍是 1.0，比港股自己調過的 1.2 窄。**

這是唯一一個有「你自己調過」證據的參數。建議：港股版**先照 1.0 跑**，看 base 數量再決定要不要 1.2。
不要一開始就改。

### 舊提示詞裡唯一要保留的港股規則

`AVOID = Minervini=0 且 RS<0`（是 **AND**，不是 OR）。v5 用 `Leader_OK` 表達同一件事，
港股版的 `Leader_OK` 判斷要改成「對 **恒指** 的相對強度」，其餘不變。

## 3. 為甚麼不是「換個 ticker」

| 港股特性 | 對系統的影響 |
|---|---|
| **每手股數不同** | `Shares_per_1000_Risk` 必須向下取整到每手，否則你會得到一個買不到的股數 |
| **中小型股極不流通** | 34 隻美股可以用固定清單；港股清單裡有幾隻日均成交 <HK$50M，訊號一多就會滑價。**流動性要變成硬閘門，不是備註** |
| **沒有季度財報** | 港股多數一年兩次（中期＋全年）。「財報 7 日內」的規則會少觸發，但 UNKNOWN 會變多 |
| **停牌常見** | 停牌後復牌可以跳空 20%＋；`BO_FAILED` 與 gap 容忍度要重新檢視 |
| **短倉數據稀缺** | 美股可用 short interest 當風險，港股只有指定證券可沽空 → 少了這條證據 |
| **指數集中** | 恒指 80 多隻，騰訊／阿里／美團權重合計很重 → 「大市」其實是幾隻股票 |
| **T+0、無 PDT** | 對 swing 影響不大，但「同日回補」的假設不同 |

## 4. 建議架構：market profile

不要 fork 一份 `us_swing_v55.py`。加一層常數：

```
markets/
  __init__.py     load(name) -> Profile
  us.py
  hk.py
```

```python
# markets/us.py
BENCH = 'SPY'; INDEX = '^IXIC'; CAL = 'XNYS'; TZ = 'America/New_York'
LOT = lambda t: 1
MIN_TURNOVER = 0
SESSION_CLOSE = '16:00'
CURRENCY = 'USD'

# markets/hk.py
BENCH = '^HSI'; INDEX = '^HSI'; CAL = 'XHKG'; TZ = 'Asia/Hong_Kong'
LOT = lambda t: LOTS.get(t, 100)      # lots_hk.csv，你維護
MIN_TURNOVER = 30e6                    # 20 日中位成交額（HKD）
SESSION_CLOSE = '16:00'
CURRENCY = 'HKD'
```

引擎只加一行：`PROFILE = markets.load(os.environ.get('SWING_MARKET', 'us'))`，
然後把 `'SPY'`、`'^IXIC'`、`'XNYS'`、`SPY` 這幾個字串換成 `PROFILE.BENCH` 等。

**好處**：同一支引擎、同一套不變量、同一份 playbook；換市場只換 profile。

### ⚠️ 這是第一個要解決的問題

3. 加 `SWING_EXPECTED_DATE` 強制檢查，資料沒到就 `DATA_STALE` 不發

我建議 **3 一定要做**，1 先試，2 看你要不要花錢。

### 為甚麼是 2800.HK 而不是 ^HSI（實測）

| 指標 | 結果 |
|---|---|
| 日回報相關 | **0.9952** |
| 1 個月 | ^HSI +2.93% ／ 2800.HK +3.23% |
| 3 個月 | ^HSI −3.77% ／ 2800.HK −2.60% |
| 16 隻港股 RS 差異 | **全部 −0.7 點**（常數偏移） |
| 跨過 RS≥10 門檻的翻轉 | **0 隻** |

原因：個股用 `auto_adjust=True`（含股息），^HSI 是**價格指數**（除息）。用指數當基準，
等於給每個派息股一點免費優勢。2800.HK 同樣含息，兩邊會計一致。
0.7 點來自 ETF 在 1M/3M 窗口的股息，方向固定、可預期。
